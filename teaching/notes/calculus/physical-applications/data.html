Tanks

The last type of problem we’ll explore in this section has to do with the work done by pumping a substance, usually a liquid, out of a tank. This requires a bit more work: the idea is that each vertical cross-section needs to be lifted a different height out of the tank, so in order to find the total work done, we find the work done by lifting a single slice out. Since the distance traveled is the same for the whole slice, that work will be a function of the height of the slice only, which we’ll typically denote . We can then integrate that work over the -values of all of the slices. This is similar to the disk method for solids of revolution given by rotating a function about the -axis, but the big difference is that these slices can be any shape.
