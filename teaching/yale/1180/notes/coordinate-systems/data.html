Section 1: Coordinate Systems

Math 1180 is in many ways an unusual course: it’s a blend of linear algebra and multivariable calculus, two topics that usually aren’t combined, and the multivariable calculus portion comes from a topic that usually isn’t split in such a manner. It’s also a terminal course in the math department, and it’s used primarily as preparation for higher-level courses in economics and statistics. All this means that the course is a unique perspective on two somewhat distinct areas of math that share one main thing in common: they concern functions of multiple variables. In the first half of this course, we’ll explore how the ideas and techniques of Calculus I — specifically optimization — apply to functions that take more than a single variable as input. In the second half, we’ll bring our experience with higher-dimensional spaces to linear algebra, exploring how formalizing and structuring methods to solve systems of linear equations results in a surprisingly rich theory that applies to far more than those systems. But before we get started with either of these, let’s take our first section to familiarize ourselves with 3D coordinates, a language common to both linear algebra and multivariable calculus.

We’re used to functions of a single variable (which we often just call functions) of the form $y = f(x)$. They take in a real number $x$ and output a real number $y$, often according to some rule like $f(x) = x^2$. When we graph functions like these, we plot pairs $(x, y)$, with one $y$-coordinate for every $x$-coordinate we can plug in.

Plenty of real-world functions take in more than one input though — a fluid has viscosity that is a function of both temperature and pressure, and a company producing multiple products that require overlapping resources has profit that is a function of the amounts of each product produced.

We could define a brand-new notion of a function of two or more variables and proceed to redevelop many of the same results we already know to be true about single-variable functions, but there’s a better way, and a good lesson to learn about math more broadly: whenever reasonable, it pays to leverage notions and language that’s already established rather than making something new from scratch. To that end, let’s think of a function that takes two inputs in a slightly different way: as a function that takes in a single pair of real numbers $(x, y)$ and outputs a real number $z$. That way, most of what we already know about single-variable functions will carry over to these new ones.

To distinguish and denote these functions, though, we’re in desperate need of notation and language! Let’s define some terms so that it’s easier to talk about these functions and others.

Definition: the real numbers

The set of all real numbers (i.e. all decimals, both rational and irrational) is denoted $\mathbb{R}$, and the set of ordered lists of $n$ real numbers is denoted $\mathbb{R}^n$ (read “R-n”).

For example, the Cartesian plane is the set of all ordered pairs of real numbers, and so we denote it $\mathbb{R}^2$. This is where graphs of single-variable functions live, and it’s also the domain of functions of two variables!

Definition: domain and codomain

Let $f$ be a function that takes inputs from a set $A$ and produces outputs in a set $B$. We say that $A$ is the domain of $f$ and that $B$ is the codomain of $f$, and we write $f : A \to B$.

The codomain of a function is distinct from its range, which is the set of all outputs of the function that actually occur. For example, the function $f : \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 2x^4$ has a codomain of $\mathbb{R}$ as it’s written (which just means its outputs are real numbers), but it has a range of $[0, \infty)$, since all real number inputs to $f$ produce positive outputs.

Our functions of interest, particularly in the second half of the course, will be functions $f : \mathbb{R}^n \to \mathbb{R}$: they take in a list of $n$ real numbers and produce a single one. While we could write something like $f((x, y)) = x + y$ to indicate that a function $f$ takes in a pair $(x, y)$ in $\mathbb{R}^2$ and sends it to $x + y$, we’ll usually omit the awkward double parentheses and just write $f(x, y) = x + y$.

Geometry in $\mathbb{R}^3$

Let’s start by getting our bearings in $\mathbb{R}^3$ specifically — while we’ll mostly be working in $\mathbb{R}^n$ for general $n$, we’ll develop much of our intuition in $\mathbb{R}^3$, since that’s the highest space we can reasonably picture (we live in a $3$-dimensional universe, after all), and nearly everything true about $\mathbb{R}^3$ that’s of use to us generalizes directly to every $\mathbb{R}^n$.

Let’s start getting our bearings in $\mathbb{R}^3$ by taking equations whose graphs we’re already familiar with in $\mathbb{R}^2$ and plotting them in 3D. Open the Desmos sidebar in the graph below and check the Extend to 3D checkbox for each equation in turn. You can also clicktap the colored circles next to the equations to hide and show them.

The results are similar for each: plotting a 2D function in 3D results in an object like a paper sheet that’s potentially curved a bit. This is exactly like graphs of vertical lines in $\mathbb{R}^2$; while we don’t think of it in this way very often, graphing an equation like $x = 2$ in $\mathbb{R}^1$ (i.e. the number line) is just a point, whereas it’s an entire vertical line in $\mathbb{R}^2$. In general, plotting a graph of an equation just means drawing all of the points where that equation is true, and adding a new variable (like $y$ in $\mathbb{R}^2$ or $z$ in $\mathbb{R}^3$) without changing the equation means there’s an entire line where the equation is true for each point there was before.

The plane defined by $x = 0$ is the unique plane that contains the $y$- and $z$-axes, and we call it the $\mathbf{yz}$-plane. Similarly, we call $y = 0$ the $\mathbf{xz}$-plane, and $z = 0$ the $\mathbf{xy}$-plane — which is fittingly enough the term we already use for $\mathbb{R}^2$ when we’re using it to graph things! Collectively, we call these three planes the coordinate planes.

We’ll talk more about how to find the equations of more general planes in the next section, but for now, let’s turn to something a little bit simpler: distance. We can compute the distance between any two points $(x_1, y_1)$ and $(x_2, y_2)$ in $\mathbb{R}^2$ by using the Pythagorean Theorem: it’s

$$\begin{alignat*}{99}d((x_1, y_1), (x_2, y_2)) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}.\end{alignat*}$$

Once again, instead of trying to reprove something like the Pythagorean Theorem in 3D, we’re best off just using it verbatim to extend the distance result to $\mathbb{R}^3$. To travel from the blue point $(x_1, y_1, z_1)$ in the graph above to the red point $(x_2, y_2, z_2)$, we can first find the distance to the purple point $(x_2, y_2, z_1)$. That’s contained in the plane $z = z_1$, and so the distance formula from $\mathbb{R}^2$ applies: the distance is

$$\begin{alignat*}{99}d' = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}.\end{alignat*}$$

Now the remainder of the distance is the vertical line from the purple point to the red one, and that distance is just $|z_2 - z_1|$. The resulting gray triangle that we form is a right triangle, and the Pythagorean Theorem tells us that its hypotenuse has length

$$\begin{alignat*}{99}d = \sqrt{d^2 + |z_2 - z_1|^2} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}.\end{alignat*}$$

Exercise: spheres and cylinders

Find equations for the following objects. For all of these, I recommend starting with an equation for the unit circle in $\mathbb{R}^2$.

2. A sphere of radius $r$ centered at $(a, b, c)$.

3. A vertical cylinder of radius $1$ parallel to the $z$-axis whose center axis contains the origin.

1. Just like the unit circle in $\mathbb{R}^2$ is given by the equation $x^2 + y^2 = 1$, or in other words the set of all points whose distance from $(0, 0)$ is equal to $1$, the unit sphere in $\mathbb{R}^3$ is given by the set of all points whose distance to the origin is $1$. Using the distance formula we just saw, that means we want $\sqrt{x^2 + y^2 + z^2} = 1$, so $x^2 + y^2 + z^2 = 1^2$.

2. Extending that idea to a sphere centered at $(a, b, c)$ and with radius $r$ means applying the distance formula again: this time,

$$\begin{alignat*}{99}(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2.\end{alignat*}$$

3. For the cylinder, there are a few different approaches. We could treat it as the set of points in $\mathbb{R}^3$ whose distance to the $z$-axis is $1$, meaning it’s defined by the equation $x^2 + y^2 = 1$, or alternatively we could think of it as the extension of the unit circle in the $xy$-plane to $\mathbb{R}^3$ — also $x^2 + y^2 = 1$.

Vectors

A natural way to think about points in $\mathbb{R}^2$ or $\mathbb{R}^3$ is as locations: a point $p = (a, b, c)$ specifies a specific location in 3D space. But most physical applications of math, particularly physics, often need a closely related concept: that of a change in location. Objects that represent a change in location — called vectors — are similar but in many ways more versatile than points, and we’ll have a lot to say about them throughout the semester! Let’s get started with a definition and some examples.

Definition: vector

A vector is a quantity that represents a difference in location (which we sometimes call displacement) between two points in space; equivalently, it’s a quantity with magnitude (the distance between the two points) and direction (the direction of travel from the starting point to the ending point). Notably, only the difference in location matters — the actual start and end points are irrelevant. We typically indicate vectors with a small arrow over a variable name, as in $\vec{v}$.

For example, the displacement $\vec{v}$ from Los Angeles to Seattle is a vector, but that vector doesn’t have anything to do with Los Angeles or Seattle specifically. In fact, $\vec{v}$ is also equal to the displacement from Seattle to somewhere in the Yukon Territories (when treating those locations as being on a 2D map, at least).

We usually draw vectors as arrows, which indicate both their magnitude and direction. As we just saw, though, the tail of the arrow doesn’t affect the value of the vector, so in the below example, dragging the red point never changes the vector; only dragging the blue point does.

While vectors are fundamentally different from points, there’s definitely a close similarity between them. In that previous graph, every position of the blue point corresponds to a vector, and vice versa. Specifically, the vector can be determined either by a magnitude and direction, or by an amount to move parallel to the $x$-axis, then an amount to move parallel to the $y$-axis (the orange dashed lines in the graph). In fact, if we place the red point at the origin, then the blue point’s coordinates tell us those amounts. This is very often an easier way to work with vectors, especially when we need a more algebraic presentation of them, so let’s write down some notation for it.

Definition: components of a vector and the zero vector

Let $\vec{v}$ be a vector in $\mathbb{R}^2$. To write $\vec{v}$ in component notation, we denote it $\vec{v} = \left< v_1, v_2 \right>$, where $v_1$ and $v_2$ are the real numbers indicating how much $\vec{v}$ moves parallel to the $x$- and $y$-axes, respectively. Similarly, a vector $\vec{w}$ in $\mathbb{R}^3$ can be written in component notation as $\vec{w} = \left< w_1, w_2, w_3 \right>$, where $w_1$, $w_2$, and $w_3$ are the amounts $\vec{w}$ moves parallel to the $x$-, $y$-, and $z$-axes.

The position vector for a point $(a, b) \in \mathbb{R}^2$ is the vector $\left< a, b \right>$ which points to $(a, b)$ when drawn from the origin. For our purposes, a point and a position vector are functionally identical — one is just written with sharper brackets and has some useful properties. (We’ll get to those in a moment!)

We also define the zero vector to be the vector with zero magnitude, which is unique as long as we know what dimension of space we’re working in. In practice, that’s clear from context, and so we use always use the symbol $\vec{0}$ to represent it, regardless of the space we’re in. In $\mathbb{R}^2$, $\vec{0} = \left< 0, 0 \right>$, in $\mathbb{R}^3$, $\vec{0} = \left< 0, 0, 0 \right>$, and so on.

Most of our vectors will be in $\mathbb{R}^2$ and $\mathbb{R}^3$, but we can just as well write $\left< 2 \right>$ for the vector with length $2$ pointing in the positive direction in $\mathbb{R}$, or $\left< -1, -2, -3, -4 \right>$ for a vector in $\mathbb{R}^4$ that we can’t very well visualize. To avoid our notation becoming clunky and obscuring what we’re trying to communicate, we’ll stick with $\mathbb{R}^3$ specifically when presenting most of the results and terminology about vectors, including for this next one.

Definition: magnitude of a vector and unit vectors

Let $\vec{v} = \left< v_1, v_2, v_3 \right>$ be a vector. The magnitude of $\vec{v}$ is

$$\begin{alignat*}{99}\left| \left| \vec{v} \right| \right| = \sqrt{v_1^2 + v_2^2 + v_3^2}.\end{alignat*}$$

In other words, it’s the length of $\vec{v}$ when it’s drawn as an arrow. A unit vector is a vector $\vec{u}$ with $\left| \left| \vec{u} \right| \right| = 1$.

Since vectors are quantities with magnitude and direction, we might want notation for the direction of a vector, too. However, no such standard notation exists. While we could use a 2D vector’s angle measured counterclockwise from the positive $x$-axis, we would need two angles in $\mathbb{R}^3$, akin to latitude and longitude. Such a system exists, and we’ll actually explore it later in the course. However, the complexity only increases in higher-dimensional spaces, and it ends up not being useful enough to justify formalizing it across all $\mathbb{R}^n$.

4. How many unit vectors are there with a first component equal to $\frac{1}{2}$ in $\mathbb{R}^2$? What about in $\mathbb{R}^3$?

1. These are the two copies of the same vector $\vec{v}$ — the have the same magnitude and direction, so they’re equal. The one that starts at $(0, 0)$ is by definition a position vector.

2. The magnitudes are $\left| \left| \vec{v} \right| \right| = \sqrt{1^2 + (-2)^2} = \sqrt{5}$ and $\left| \left| \vec{w} \right| \right| = \sqrt{14}$.

3. The set of all unit vectors in $\mathbb{R}^2$ is the set of all $\left< v_1, v_2 \right>$ with $\sqrt{v_1^2 + v_2^2} = 1$, so if we draw all the vectors starting from the origin, then it’s a circle! Similarly, the set of all unit vectors in $\mathbb{R}^3$ is a sphere.

4. If the first component is equal to $\frac{1}{2}$ in $\mathbb{R}^2$, then we can solve

$$\begin{alignat*}{99}\sqrt{\left( \frac{1}{2} \right)^2 + v_2^2} &= 1\\\frac{1}{4} + v_2^2 &= 1\\v_2 &= \pm \sqrt{\frac{3}{4}}\\&= \pm \frac{\sqrt{3}}{2}.\end{alignat*}$$

Therefore, the only two vectors are $\left< \frac{1}{2}, \frac{\sqrt{3}}{2} \right>$ and $\left< \frac{1}{2}, -\frac{\sqrt{3}}{2} \right>$.

In $\mathbb{R}^3$, that same equation results in

$$\begin{alignat*}{99}\frac{1}{4} + v_2^2 + v_3^2 &= 1\\v_2^2 + v_3^2 &= \frac{3}{4},\end{alignat*}$$

which is a little more complicated: it means that the 2D vector $\left< v_2, v_3 \right>$ has magnitude $\frac{\sqrt{3}}{2}$. If we still center all our vectors at the origin, then these vectors appear as a circle on the unit sphere at $x = \frac{1}{2}$. We can also think of it as the intersection of the plane $x = \frac{1}{2}$ with the unit sphere!

Going back to our flight example, the notion of vectors as displacements works nicely if we want to add them together: in a sense, the displacement from Los Angeles to Seattle combined with the displacement from Seattle to New York is like taking a two-leg flight, and the total should equal the displacement from Los Angeles to New York. This is exactly the notion of adding vectors geometrically: we place the vectors so that first one ends where the second one starts, and then draw the sum of the two as the vector that stretches from the start of the first to the end of the second.

Here, the sum of the red and blue vectors is the purple one — and notice that we can add the vectors in either order to get the same result! That’s a concise visual justification that vector addition is commutative.

Vector addition also plays nicely with components. If $\vec{v} = \left< v_1, v_2, v_3 \right>$ and $\vec{w} = \left< w_1, w_2, w_3 \right>$, then the combination $\vec{v} + \vec{w}$ moves a total of $v_1 + w_1$ in the $x$-direction and so on, meaning

$$\begin{alignat*}{99}\vec{v} + \vec{w} = \left< v_1 + w_1, v_2 + w_2, v_3 + w_3 \right>.\end{alignat*}$$

With the knowledge of how to add vectors, we can also make sense of scalar multiplication: how to multiply a vector by a constant number (i.e. a scalar, which here means not a vector). For example, any vector $\vec{v}$ should satisfy $\vec{v} + \vec{v} = 2\vec{v}$, where $2\vec{v}$ is an operation we’ll need to define. But $\vec{v} + \vec{v}$ is just the result of placing $\vec{v}$ at the end of itself, meaning it’s a vector in the same direction as $\vec{v}$, but twice as long. More generally, we can define scalar multiplication as follows:

Definition: scalar multiplication of vectors

Let $\vec{v}$ be a vector and let $c > 0$ be a real number. Then $c\vec{v}$ is the vector in the same direction as $\vec{v}$, but $c$ times as long — that is, $\left| \left| c\vec{v} \right| \right| = c \cdot \left| \left| \vec{v} \right| \right|$.

If $c < 0$, then $c\vec{v}$ is the vector in the opposite direction as $\vec{v}$, and $|c|$ times as long. Finally, if $c = 0$, then $c\vec{v} = 0\vec{v} = \vec{0}$. In general, $\left| \left| c\vec{v} \right| \right| = |c| \cdot \left| \left| \vec{v} \right| \right|$.

Exercise: finding unit vectors

Let $\vec{v}$ be any vector other than the zero vector. What is a formula for a unit vector in the same direction as $\vec{v}$? Geometrically, why doesn’t this formula work for the zero vector?

Any vector in the same direction as $\vec{v}$ has the form $c\vec{v}$ for some positive number $c$, so if we want $c\vec{v}$ to be a unit vector, we need

$$\begin{alignat*}{99}\left| \left| c\vec{v} \right| \right| = |c| \cdot \left| \left| \vec{v} \right| \right| = 1.\end{alignat*}$$

That means $|c| = \frac{1}{\left| \left| \vec{v} \right| \right|}$, and so

$$\begin{alignat*}{99}c = \pm \frac{1}{\left| \left| \vec{v} \right| \right|}.\end{alignat*}$$

The negative version would point in the opposite direction as $\vec{v}$, so we want the positive one; that is, a formula for a unit vector in the same direction as $\vec{v}$ is

$$\begin{alignat*}{99}\frac{v}{\left| \left| \vec{v} \right| \right|}.\end{alignat*}$$

Since the zero vector has zero magnitude, we’d be dividing by zero! Geometrically, the zero vector doesn’t have a direction.

While it might seem like vector multiplication is just a definition away, there are unfortunately unsolvable difficulties with trying to define $\vec{v}\vec{w}$ by multiplying corresponding components. For one, any vector with a zero in any component wouldn’t have a multiplicative inverse. We’ll look into alternatives that will sort of let us multiply vectors in the next section, but for now, we’re going to leave vector multiplication completely undefined.

Let’s take a moment to summarize some properties of vector addition and scalar multiplication, and then we’ll define some useful terminology.

Proposition: properties of vector arithmetic

For any vectors $\vec{u}$, $\vec{v}$ and $\vec{w}$,

1. $\vec{u} + \left( \vec{v} + \vec{w} \right) = \left( \vec{u} + \vec{v} \right) + \vec{w}$ (i.e. vector addition is associative).

2. $\vec{v} + \vec{w} = \vec{w} + \vec{v}$ (i.e. vector addition is commutative).

3. $\vec{v} + \vec{0} = \vec{v}$.

4. $0\vec{v} = \vec{0}$.

5. $\vec{v} - \vec{v} = \vec{0}$.

6. $c\left( \vec{v} + \vec{w} \right) = c\vec{v} + c\vec{w}$ and $(c + d)\vec{v} = c\vec{v} + d\vec{v}$ for any numbers $c$ and $d$ (i.e. scalar multiplication of vectors is distributive).

7. $\left| \left| c\vec{v} \right| \right| = |c| \cdot \left| \left| \vec{v} \right| \right|$ for any number $c$.

8. The only vector $\vec{v}$ with $\left| \left| \vec{v} \right| \right| = 0$ is $\vec{v} = \vec{0}$.

When we a vector $\vec{v}$ in $\mathbb{R}^2$ as $\left< v_1, v_2 \right>$, we can think of it as the sum $\vec{v} = \left< v_1, 0 \right> + \left< 0, v_2 \right>$, or equivalently, $\vec{v} = v_1 \left< 1, 0 \right> + v_2\left< 0, 1 \right>$. That decomposition will prove useful, and we’ll give those two vectors names to better handle them.

Definition: standard basis vectors

In $\mathbb{R}^2$, we define $\vec{i} = \left< 1, 0 \right>$ and $\vec{j} = \left< 0, 1 \right>$, and in $\mathbb{R}^3$, $\vec{i} = \left< 1, 0, 0 \right>$, $\vec{j} = \left< 0, 1, 0 \right>$, and $\vec{k} = \left< 0, 0, 1 \right>$.
