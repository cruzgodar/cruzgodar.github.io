Definition: linear independence

A collection of vectors is linearly dependent if there is a linear combination of the that is equal to the zero vector (other than the linear combination with every coefficient equal to zero). A collection of vectors is linearly independent if it is not linearly dependent; that is, the only linear combination that equals the zero vector is when all the coefficients are zero.
