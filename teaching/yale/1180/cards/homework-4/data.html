1. Let $f(x, y) = \dfrac{e^{x - y}}{y}$. Compute $\nabla\! f$ and $D_{\vec{u}}f(3, 1)$, where $\vec{u} = \left< \dfrac{2}{\sqrt{5}}, -\dfrac{1}{\sqrt{5}} \right>$.

Solution: We have

$$\begin{alignat*}{99}f_x(x, y) &= \frac{e^{x - y}}{y}\\[4px]f_y(x, y) &= \frac{-e^{x - y} \cdot y - e^{x - y}}{y^2}\\[4px]&= -\frac{(y + 1)e^{x - y}}{y^2}.\end{alignat*}$$

Therefore,

$$\begin{alignat*}{99}\nabla\! f &= \left< \frac{e^{x - y}}{y}, -\frac{(y + 1)e^{x - y}}{y^2} \right>\\[4px]\nabla\! f(3, 1) &= \left< e^2, -2e^2 \right>.\end{alignat*}$$

Since $\vec{u}$ is already a unit vector, we can directly compute

$$\begin{alignat*}{99}D_{\vec{u}}f(3, 1) &= \left< e^2, -2e^2 \right> \bullet \left< \frac{2}{\sqrt{5}}, -\frac{1}{\sqrt{5}} \right>\\[4px]&= \frac{2e^2}{\sqrt{5}} + \frac{2e^2}{\sqrt{5}}\\[4px]&= \frac{4e^2}{\sqrt{5}}.\end{alignat*}$$

2. Let $g(x, y, z) = x^2 + x^y + \sin(xyz)$. Compute $\nabla\! g$ and $D_{\vec{u}}g(3, 2, 0)$, where $\vec{u}$ points in the direction of $\left< 1, 1, 1 \right>$.

Solution:

$$\begin{alignat*}{99}\nabla\! g &= \left< 2x + yx^{y-1} + yz\cos(xyz),\ x^y\ln(x) + xz\cos(xyz),\ xy\cos(xyz) \right>\\[4px]\nabla\! g(3, 2, 0) &= \left< 12,\ 9\ln(3),\ 6 \right>.\end{alignat*}$$

The vector $\left< 1, 1, 1 \right>$ has magnitude $\sqrt{3}$, so we normalize it to $\vec{u} = \left< \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{3}} \right>$ before using the gradient. Then

$$\begin{alignat*}{99}D_{\vec{u}}g(3, 2, 0) &= \left< 12,\ 9\ln(3),\ 6 \right> \bullet \left< \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{3}} \right>\\[4px]&= \frac{1}{\sqrt{3}}\left( 18 + 9\ln(3) \right).\end{alignat*}$$

3. Let $f(x, y)$ be a function so that $D_{\vec{u}}f(4, 5) = 5$ and $D_{\vec{v}}f(4, 5) = 11$, where $\vec{u}$ points in the same direction as $\left< 5, 12 \right>$ and $\vec{v} = \left< \frac{3}{5}, \frac{4}{5} \right>$. What is $\nabla\! f (4, 5)$?

Solution: Let $\nabla\! f(4, 5) = \left< a, b \right>$. First, $\vec{u}$ needs to be a unit vector, so we normalize $\left< 5, 12 \right>$ to $\vec{u} = \left< \frac{5}{13}, \frac{12}{13} \right>$. The vector $\vec{v}$ is already a unit vector, so

$$\begin{alignat*}{99}D_{\vec{u}}f(4, 5) &= \frac{5a + 12b}{13} = 5\\[4px]D_{\vec{v}}f(4, 5) &= \frac{3a + 4b}{5} = 11.\end{alignat*}$$

That means $5a + 12b = 65$ and $3a + 4b = 55$, which results in $a = 25$ and $b = -5$, and so

$$\begin{alignat*}{99}\nabla\! f(4, 5) = \left< 25, -5 \right>.\end{alignat*}$$

The point is that any two non-parallel directions are enough to pin down the gradient; we’ll discuss this more in the second half of the course!

4. Let $\displaystyle f(x, y) = 2(y - 2x)^{3/2}$. Find the equation for the tangent line to the graph of $f$ at $(2, 6)$ in the direction $\left< -1, -1 \right>$.

Solution: We need a point and a direction. The point is

$$\begin{alignat*}{99}(2, 6, f(2, 6)) = \left( 2, 6, 2\sqrt{8}\right).\end{alignat*}$$

For the direction, moving along a unit vector $\vec{u}$ in the $xy$-plane changes $z$ by $D_{\vec{u}}f(2, 6)$. We have

$$\begin{alignat*}{99}\nabla\! f &= \left< -6(y - 2x)^{1/2}, 3(y - 2x)^{1/2} \right>\\[4px]\nabla\! f(2, 6) &= \left< -6\sqrt{2}, 3\sqrt{2} \right>.\end{alignat*}$$

Normalizing $\left< -1, -1 \right>$ to $\vec{u} = \left< -\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}} \right>$, we get

$$\begin{alignat*}{99}D_{\vec{u}}f(2, 6) = 6 - 3 = 3.\end{alignat*}$$

A direction vector for the tangent line is therefore $\left< -\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}}, 3 \right>$, so the tangent line is

$$\begin{alignat*}{99}\vec{r}(t) = \left< 2, 6, 2\sqrt{8} \right> + t\left< -\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}}, 3 \right>.\end{alignat*}$$

5. Let $f(x, y)$ be a function differentiable at $(a, b)$, and let $\vec{g} = \left< 1, 1, f_x(a, b) + f_y(a, b) \right>$. Show that $\vec{g}$ is parallel to the tangent plane to $f$ at $(a, b)$. (Hint: how can you rephrase that in terms of the normal vector to the tangent plane?)

Solution: The tangent plane is $z = f(a, b) + f_x(a, b)(x - a) + f_y(a, b)(y - b)$, which we can rewrite as

$$\begin{alignat*}{99}f_x(a, b)(x - a) + f_y(a, b)(y - b) - \left( z - f(a, b) \right) = 0.\end{alignat*}$$

One normal vector is therefore $\vec{n} = \left< f_x(a, b), f_y(a, b), -1 \right>$. Then

$$\begin{alignat*}{99}\vec{n} \bullet \vec{g} &= f_x(a, b) + f_y(a, b) - \left( f_x(a, b) + f_y(a, b) \right)\\[4px]&= 0,\end{alignat*}$$

which means $\vec{g}$ is orthogonal to the normal vector, or in other words parallel to the plane.

6. A variable $w$ is given by $w = f(x, y, z)$, where $x = x(a)$, $y = y(a, b, c)$, and $z = z(x, a, c)$.

a) Express $\frac{\partial w}{\partial a}$ using the multivariable Chain Rule.

b) If $\frac{\partial w}{\partial c} = 2$, $\frac{\partial w}{\partial y} = 1$, $\frac{\partial w}{\partial z} = 3$, and $\frac{\partial z}{\partial c} = -4$, what is $\frac{\partial y}{\partial c}$?

Solution:

a) Adding up the products along each branch,

$$\begin{alignat*}{99}\frac{\partial w}{\partial a} = \frac{\partial w}{\partial x} \frac{\mathrm{d}x}{\mathrm{d}a} + \frac{\partial w}{\partial y} \frac{\partial y}{\partial a} + \frac{\partial w}{\partial z} \frac{\partial z}{\partial x} \frac{\mathrm{d}x}{\mathrm{d}a} + \frac{\partial w}{\partial z} \frac{\partial z}{\partial a}.\end{alignat*}$$

Since $x$ is a function of only $a$, its derivative gets a $\mathrm{d}$ rather than a $\partial$.

b) There are two paths from $w$ to $c$: one through $y$ and one through $z$.

$$\begin{alignat*}{99}\frac{\partial w}{\partial c} &= \frac{\partial w}{\partial y} \frac{\partial y}{\partial c} + \frac{\partial w}{\partial z} \frac{\partial z}{\partial c}\\[4px]2 &= (1) \frac{\partial y}{\partial c} + (3)(-4),\end{alignat*}$$

and so $\frac{\partial y}{\partial c} = 14$.

Problems 7–10 concern the following situation. Steep cafe finds that the number of cups of cold brew it sells per week is

$$\begin{alignat*}{99}C(p, l, s) = \frac{900\sqrt{l}}{p + s},\end{alignat*}$$

where $p$ is Steep’s price for a cup of cold brew, $s$ is its price for a scone, and $l$ is the price of a canned latte from the nearby cooler, all in dollars. Right now, $p = 4$, $l = 4$, and $s = 2$. Two goods are called substitutes if raising the price of one increases the demand for the other, and complements if raising the price of one decreases the demand for the other (we explored this briefly in past problem sets).

7. Compute $C$ and all of its partial derivatives at these current prices, including units. Are canned lattes and cold brew substitutes or complements? What about scones and cold brew?

Solution: At the current prices,

$$\begin{alignat*}{99}C(4, 4, 2) = \frac{900\sqrt{4}}{4 + 2} = 300,\end{alignat*}$$

so Steep currently sells $300$ cups of cold brew per week. The partials are

$$\begin{alignat*}{99}\frac{\partial C}{\partial p} &= -\frac{900\sqrt{l}}{(p + s)^2}\\[4px]\frac{\partial C}{\partial l} &= \frac{450}{\sqrt{l}(p + s)}\\[4px]\frac{\partial C}{\partial s} &= -\frac{900\sqrt{l}}{(p + s)^2},\end{alignat*}$$

which at current prices are

$$\begin{alignat*}{99}\frac{\partial C}{\partial p}(4, 4, 2) &= -\frac{1800}{36} = -50\\[4px]\frac{\partial C}{\partial l}(4, 4, 2) &= \frac{450}{12} = 37.5\\[4px]\frac{\partial C}{\partial s}(4, 4, 2) &= -\frac{1800}{36} = -50,\end{alignat*}$$

all in cups per week, per dollar. Since $\frac{\partial C}{\partial l} > 0$, canned lattes and cold brew are substitutes (when lattes get more expensive, some latte drinkers switch to cold brew). Since $\frac{\partial C}{\partial s} < 0$, scones and cold brew are complements (some customers buy a scone along with their cold brew, so more expensive scones make the whole trip less appealing).

8. Suppose all three prices are changing: the price of a cup of cold brew is increasing at $\$0.10$ per month, the price of a canned latte is increasing at $\$0.40$ per month (sadly), and the price of a scone is decreasing at $\$0.05$ per month. How fast is Steep’s weekly sales of cold brew increasing? Why is it increasing even though cold brew is getting more expensive?

Solution: Let $t$ be time in months. By the multivariable chain rule,

$$\begin{alignat*}{99}\frac{\mathrm{d}C}{\mathrm{d}t} &= \frac{\partial C}{\partial p} \frac{\mathrm{d}p}{\mathrm{d}t} + \frac{\partial C}{\partial l} \frac{\mathrm{d}l}{\mathrm{d}t} + \frac{\partial C}{\partial s} \frac{\mathrm{d}s}{\mathrm{d}t}\\[4px]&= (-50)(0.1) + (37.5)(0.4) + (-50)(-0.05)\\[4px]&= -5 + 15 + 2.5\\[4px]&= 12.5.\end{alignat*}$$

Steep’s weekly cold brew sales are increasing at $12.5$ cups per week each month. The rising price of cold brew on its own would cost it $5$ cups per week every month, but the rising price of canned lattes and the falling price of scones make up for it.

9. Both the cold brew and scones use milk, so Steep sets their prices based on the wholesale price $m$ of a gallon of milk: $p = 2 + m$ and $s = 1 + \frac{m}{2}$. Currently, $m = 2$. Draw a tree diagram for $C$ as a function of $m$ and $l$, and use it to compute $\frac{\partial C}{\partial m}$. Interpret the meaning of $\frac{\partial C}{\partial m}$ in a sentence.

Solution: There are two paths from $C$ down to $m$: one through $p$ and one through $s$. Since $\frac{\mathrm{d}p}{\mathrm{d}m} = 1$ and $\frac{\mathrm{d}s}{\mathrm{d}m} = \frac{1}{2}$,

$$\begin{alignat*}{99}\frac{\partial C}{\partial m} &= \frac{\partial C}{\partial p} \frac{\mathrm{d}p}{\mathrm{d}m} + \frac{\partial C}{\partial s} \frac{\mathrm{d}s}{\mathrm{d}m}\\[4px]&= (-50)(1) + (-50)\left( \frac{1}{2} \right)\\[4px]&= -75.\end{alignat*}$$

Every dollar increase in the wholesale price of a gallon of milk costs Steep about $75$ cups of cold brew sales per week.

10. On average, Steep sells one scone for every two cups of cold brew, so it sells $S = \frac{C}{2}$ scones per week, and its total weekly revenue is $R = pC + sS$. First, express $R$ as a function of $p$, $l$, and $s$. Then compute $\frac{\partial R}{\partial s}$ at the current prices. Stores sometimes deliberately set a low price on one item to bring in customers; that item is called a loss leader. Should Steep consider making its scones a loss leader?

Solution: We have

$$\begin{alignat*}{99}R &= p\left( \frac{900\sqrt{l}}{p + s} \right) + s\left( \frac{450\sqrt{l}}{p + s} \right)\\[4px]&= \left( \frac{450\sqrt{l}}{p + s} \right)\left( 2p + s \right),\end{alignat*}$$

so

$$\begin{alignat*}{99}\frac{\partial R}{\partial s} &= \left( -\frac{450\sqrt{l}}{(p + s)^2} \right)\left( 2p + s \right) + \left( \frac{450\sqrt{l}}{p + s} \right)\\[4px]\frac{\partial R}{\partial s} (4, 4, 2) &= \left( -\frac{900}{36} \right)\left( 10 \right) + \left( \frac{900}{6} \right)\\[4px]&= -250 + 150\\[4px]&= -100.\end{alignat*}$$

Raising the price of a scone by a dollar would decrease weekly revenue by approximately $\$100$. On the other hand, lowering the price of scones increases Steep’s total revenue, so it should consider making them a loss leader. Note that this only measures revenue, not profit, so whether it’s actually worth it depends on how much each scone costs to make, and the derivative only tells us about small changes near the current prices, so the “approximately” $\$100$ might be very far off, considering decreasing $s$ by $1$ is halving its current value.
